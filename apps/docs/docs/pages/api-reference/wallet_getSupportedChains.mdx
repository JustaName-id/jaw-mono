# wallet_getSupportedChains

Get the list of chains supported by the wallet infrastructure.

**Authentication Required:** API key (as `x-api-key` header or `api-key` query param); no user session needed

:::warning
This method is served by the RPC proxy but is **not exposed through the SDK provider** — `jaw.provider.request({ method: 'wallet_getSupportedChains' })` throws `unsupported method`. Call the proxy's JSON-RPC endpoint directly. SDK users can derive the supported chains from the keys of [wallet_getCapabilities](/api-reference/wallet_getCapabilities) instead.
:::

## Request

```bash
curl -X POST https://api.justaname.id/proxy/v1/rpc/handle \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: <your-api-key>' \
  -d '{"jsonrpc":"2.0","id":1,"method":"wallet_getSupportedChains","params":[{"showTestnets":true}]}'
```

### Parameters

| Name           | Type      | Required | Description                                 |
| -------------- | --------- | -------- | ------------------------------------------- |
| `showTestnets` | `boolean` | No       | Include testnet chains. Defaults to `false` |

Params may be omitted entirely; the default returns mainnet chains only.

```json
[{ "showTestnets": false }]
```

## Response

Returns an array of supported chain IDs in hex format.

**Type:** `string[]`

### Example

```json
["0x1", "0x2105", "0xa4b1"]
```

## Behavior

- Requires an API key but no user session
- Returns mainnet chains by default; pass `showTestnets: true` to include testnets
- Unlike `wallet_getCapabilities` and `wallet_getAssets`, the testnet filter for this method is applied **server-side**
